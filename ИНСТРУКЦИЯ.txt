ADVISOR AI — ЛИЧНЫЙ КАБИНЕТ

Файлы для загрузки в уже созданный публичный репозиторий GitHub advisor-ai-website:
  index.html — главная страница с кнопкой входа в кабинет
  workspace.html — новый кабинет, работает уже сейчас локально
НЕ загружайте supabase_setup.sql в публичный репозиторий, он предназначен для выполнения в Supabase SQL Editor.

ШАГ 1. Загрузите index.html и workspace.html через https://github.com/ablaiskiy5/advisor-ai-website/upload/main и Commit changes.
ШАГ 2. Откройте https://ablaiskiy5.github.io/advisor-ai-website/workspace.html
ШАГ 3. Создавайте кейсы: Портфели / Идеи / Обучение / Рынки / Задачи. Данные сохраняются локально в браузере.

ДЛЯ ОБЛАКА (позже):
1. Создайте проект Supabase https://supabase.com/dashboard и настройте email auth.
2. В Supabase SQL Editor выполните supabase_setup.sql.
3. В кабинете Настройки вставьте Project URL и ТОЛЬКО Publishable/anon key, нажмите Подключить базу.
4. Создайте аккаунт через email и пароль, подтвердите email, войдите.
5. Теперь записи сохраняются между устройствами в Supabase с индивидуальными RLS-политиками.
6. Старые локальные записи можно перенести через Настройки → Скачать копию JSON, затем войти в облако и выбрать Импорт JSON.

ВАЖНО: это личный рабочий органайзер, НЕ корпоративная CRM. Не сохраняйте в нём ФИО клиентов, номера счетов, выписки, скриншоты позиций или персональные данные до согласования с политикой безопасности работодателя.
Интеграция с ChatGPT — через явное сохранение URL диалога, история чатов автоматически НЕ подтягивается.
Не вставляйте в публичные файлы секретные ключи Supabase.
