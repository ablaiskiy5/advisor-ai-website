Политика конфиденциальности

Обновлено: 20 октября 2026 года. Эта политика описывает информационный сайт и личный рабочий кабинет Advisor AI | Investments.

Данные на сайте

В локальном режиме заметки, заголовки кейсов, статусы и ссылки на чаты сохраняются в localStorage браузера на вашем устройстве. При добровольном подключении Supabase и регистрации эти данные хранятся в выбранном Supabase-проекте, а поставщик обрабатывает email и данные авторизации. В облачном режиме используются сессионные данные авторизации. Доступ к таблице записей ограничивается правилами row-level security, но абсолютная безопасность не гарантируется. Хостинг GitHub Pages и сторонние поставщики могут обрабатывать технические журналы запросов по своим правилам.

Плагин и MCP

При использовании ChatGPT обработка сообщений регулируется правилами OpenAI. Сайт не получает содержание истории ChatGPT автоматически; сохраняются только ссылки, которые пользователь сам добавляет. Отдельный MCP-сервис на Render получает входные числовые параметры калькулятора облигаций и отправляет ответ; он не требует ФИО или номеров брокерских счетов. Публикация плагина находится на модерации.

Безопасность

Не загружайте клиентские персональные данные, номера счетов, закрытые выписки и коммерческую тайну без согласования с работодателем. Для удаления локальных данных используйте настройки браузера; для облачных записей — удаление кейсов или запрос по контактному email. Доступ и сроки хранения у внешних провайдеров зависят от их правил.

Используемые сервисы

GitHub Pages (публичный сайт), Supabase (опциональная авторизация и база), Render (MCP), OpenAI ChatGPT (AI-чаты). Данные передаются сервисам только в рамках соответствующей функции.
